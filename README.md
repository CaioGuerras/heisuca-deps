# heisuca-deps

Mirror of two public build inputs used by the Heisuca Android CI, kept so a build does not fail when the origin is down.
Files are unmodified copies; each release lists the origin and the SHA-256 that the build verifies.

| --- | --- | --- |
| ffmpeg-8.0.1.tar.xz | https://ffmpeg.org/releases/ | LGPL-2.1+ / GPL (see the tarball) |
| libass-android-0.18.3.zip | https://github.com/edde746/libass/releases | ISC (libass) and bundled library licenses; see the archive |
